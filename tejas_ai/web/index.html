    Use Tejas on another screen

    Your phone, tablet or TV must be on the same home Wi-Fi. Scan the code, or type the address.

    1. On the iPhone, open Safari and type the address above, or scan the code with the Camera. If Safari says the connection isn’t private, tap Show Details → visit this website (it’s your own computer).
    2. Tap Tejas home certificate on that page, then Allow. Go to Settings → Profile Downloaded → Install.
    3. Then Settings → General → About → Certificate Trust Settings and switch on Tejas Home CA. Now the page is secure and the microphone works.
    4. Back in Safari, open the address again and tap Share → Add to Home Screen. Tejas now opens full-screen from its own icon, like an app.
