# JK — Cinematic Portfolio

A storyboard-style creative portfolio built around continuous scroll storytelling.

## Stack

- React + Vite
- GSAP + ScrollTrigger
- Lenis smooth scrolling
- Responsive CSS

## Run locally

```bash
npm install
npm run dev
```

Replace the temporary Unsplash project imagery in `src/main.jsx` with final portfolio assets/video when ready.
